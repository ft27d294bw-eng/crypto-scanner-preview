CRYPTO SCANNER v0.8 — AZURE EDITION
=================================

ЗАПУСК ОНОВЛЕННЯ НА GITHUB PAGES — без Render, npm і Terminal

1. Завантаж ZIP CryptoScanner_v0.8_AZURE_GITHUB_PAGES.zip.
2. На Mac двічі натисни на ZIP, щоб розпакувати.
3. Відкрий розпаковану папку. У ній мають бути файли:
   index.html, manifest.webmanifest, sw.js, icon-192.png,
   icon-512.png, apple-touch-icon.png, START_HERE_UA.txt
4. Відкрий свій репозиторій:
   https://github.com/ft27d294bw-eng/crypto-scanner-preview
5. Натисни Add file → Upload files.
6. Перетягни УСІ сім файлів ІЗ розпакованої папки (не ZIP).
   GitHub замінить старий index.html новою версією.
   Нічого не видаляй. Не завантажуй .env, паролі чи API-ключі.
7. Натисни Commit changes.
8. Відкрий:
   https://ft27d294bw-eng.github.io/crypto-scanner-preview/
   Якщо показує стару версію: у Safari натисни Cmd+Option+R
   або відкрий сайт у приватному вікні. НЕ Cmd+Shift+R (Reader).

IPHONE
У Safari відкрий сайт → Поділитися → На початковий екран / Add to Home Screen.
Назва додатка: Crypto Scanner. Для повної іконки та кешу потрібні
всі файли з ZIP, не тільки index.html.

  проскальзування та заданих витрат на перевід.
• Сигнали про спреди лише у відкритому вікні браузера.

  та ще кілька валют, ціна купівлі у вибраній валюті.
• Більше монет доступно для додавання до портфеля.
• RU / EN, теми, профіль, FX-конвертер, золото, Reality Check.
• PWA manifest та service worker. Дані ринку не кешуються офлайн.

ВАЖЛИВІ ОБМЕЖЕННЯ
• Реєстрація через email вимкнена: GitHub Pages — статичний хостинг.
  Потрібні сервер, постійна база, захищений email-сервіс.
• Профіль, обране та портфель зберігаються тільки в браузері.
  Не видаляй дані браузера, якщо вони важливі. Експорт даних портфеля
  ще не реалізовано; не вважай його системою резервного копіювання.
• API бірж можуть не відповідати через CORS, регіональні блокування
  або ліміти. Відсутні дані позначаються, не підміняються демоцінниками.
• Котирування у режимі ?demo=1 вигадані.
• FX з Frankfurter — довідкові денні курси, не ціни обміну.
• Показники прибутку — гіпотетичні. Не враховано фактичну можливість
  переказу монет між біржами, повну глибину стакана, комісії мережі,
  затримки, податки та інші ризики. Не є фінансовою порадою.
• Конвертація середньої ціни купівлі відбувається за ПОТОЧНИМ
  довідковим валютним курсом на час додавання позиції, не історичним.
• Сповіщення при закритому сайті й акаунти між пристроями — наступний
  серверний етап, зараз вони НЕ реалізовані.
